# Security Policy

## Reporting Security Issues

The kpt maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/kptdev/kpt/security/advisories/new) form.

For more details, see the [kpt security policy](https://github.com/kptdev/kpt/blob/main/SECURITY.md).
