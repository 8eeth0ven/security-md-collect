# Security

See [CONTRIBUTING](CONTRIBUTING.md#security-issue-notifications) for more information.

## Reporting Security Issues

If you discover a potential security issue in this project, we ask that you notify AWS/Amazon Security via our
[vulnerability reporting page](http://aws.amazon.com/security/vulnerability-reporting/). Please do **not** create a public
GitHub issue.

For details on the security architecture and controls implemented in this pattern, see [docs/SECURITY.md](docs/SECURITY.md).
