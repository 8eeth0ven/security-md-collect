# Security Policy

## Reporting a Vulnerability

NVIDIA takes security seriously. If you discover a potential security
vulnerability in this project, please report it responsibly.

**Please do NOT file a public issue for security vulnerabilities.**

Instead, report security concerns to NVIDIA's Product Security Incident
Response Team (PSIRT):

- **Email:** [psirt@nvidia.com](mailto:psirt@nvidia.com)
- **NVIDIA Security Page:** [https://www.nvidia.com/en-us/security/](https://www.nvidia.com/en-us/security/)

### What to Include

When reporting a vulnerability, please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested remediation (if applicable)

### Response Timeline

NVIDIA PSIRT will acknowledge receipt of your report and work with you to
understand and address the issue. We aim to respond to vulnerability reports
within 5 business days.

## Supported Versions

Security updates are provided for the latest release on the `main` branch.
