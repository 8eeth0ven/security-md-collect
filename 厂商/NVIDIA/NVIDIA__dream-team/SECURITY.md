# Security

NVIDIA is dedicated to the security and trust of its software products and
services, including source code repositories managed by NVIDIA.

## Reporting a vulnerability

Do not report security vulnerabilities through a public GitHub issue,
discussion, or pull request.

Report a potential vulnerability to the NVIDIA Product Security Incident
Response Team (PSIRT):

- Web: <https://www.nvidia.com/en-us/support/submit-security-vulnerability/>
- Email: <psirt@nvidia.com>

When reporting by email, use the NVIDIA public PGP key linked from the
[NVIDIA Product Security page](https://www.nvidia.com/en-us/security/report-vulnerability/)
when possible. Include the affected version or commit, the vulnerability
type, reproduction instructions, proof-of-concept information, and the
potential impact.

## Supported versions

Security fixes are provided for the latest public release. Older revisions
may not receive security updates.
