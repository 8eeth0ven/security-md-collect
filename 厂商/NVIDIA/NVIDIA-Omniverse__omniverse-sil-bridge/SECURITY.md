# Security Policy

## Supported versions

This project is under active development. Security fixes are assessed for the
current default branch. Earlier snapshots and untagged development builds are
not supported.

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Report a potential vulnerability through NVIDIA's
[Product Security Incident Response Team (PSIRT) reporting process](https://www.nvidia.com/en-us/security/report-vulnerability/).
Include the affected component, repository revision, a description of the
issue, reproduction steps or proof of concept, and the potential impact.

NVIDIA PSIRT evaluates reports and coordinates remediation and disclosure in
accordance with its published policies. Please give the team a reasonable time
to investigate and address a report before publicly disclosing it.
