# Security Policy

## Reporting Security Issues

Google takes the security of our software products and services seriously, including the open source code repositories managed through our Google organizations on GitHub.

If you believe you have found a security vulnerability in this repository that meets [Google's definition of a security vulnerability](https://www.google.com/about/appsecurity/), please report it to us at [Google Bug Hunters](https://bughunters.google.com/) or contact [security@google.com](mailto:security@google.com).

Please **do NOT** report security vulnerabilities through public GitHub issues, discussions, or pull requests.
